### سؤال 1: نرمال‌سازی و اثر آن روی KNN

**فایل:** `question1_normalization_knn.py`

**دیتاست:** Diamonds (از کتابخانه Seaborn)

**هدف:** بررسی تأثیر روش‌های مختلف نرمال‌سازی بر دقت الگوریتم K-Nearest Neighbors

#### مراحل انجام کار:

1. **بارگذاری و تحلیل داده:**
   - بارگذاری دیتاست diamonds
   - استخراج ویژگی‌های عددی: `carat`, `depth`, `table`, `price`, `x`, `y`, `z`

2. **رسم نمودارها:**
   - هیستوگرام برای هر ویژگی (نمایش توزیع داده)
   - باکس‌پلات برای هر ویژگی (شناسایی outliers)

3. **آماده‌سازی داده:**
   - تبدیل متغیر هدف `cut` به اعداد (0-4)
   - تقسیم داده به train/test با نسبت 80/20

4. **مقایسه روش‌های نرمال‌سازی:**
   - **بدون نرمال‌سازی:** استفاده از داده خام
   - **Min-Max Scaling:** مقیاس‌دهی به بازه [0, 1]
   - **Z-score (StandardScaler):** استانداردسازی با میانگین 0 و انحراف معیار 1

#### نتیجه مورد انتظار:
نرمال‌سازی معمولاً دقت KNN را بهبود می‌بخشد زیرا این الگوریتم بر اساس فاصله کار می‌کند و ویژگی‌هایی با مقیاس بزرگتر تأثیر بیشتری دارند.

### سؤال 2: باینینگ و هموارسازی

**فایل:** `question2_binning_smoothing.py`

**دیتاست:** Titanic (از کتابخانه Seaborn)

**هدف:** آشنایی با روش‌های باینینگ و هموارسازی داده

#### مراحل انجام کار:

1. **Equal-Width Binning (باینینگ با عرض مساوی):**
   - تقسیم سن به 4 بازه با عرض برابر: 0-20، 20-40، 40-60، 60-80
   - استفاده از `pd.cut()`

2. **Equal-Frequency Binning (باینینگ با فراوانی مساوی):**
   - تقسیم سن به 4 چارک با تعداد تقریباً برابر
   - استفاده از `pd.qcut()`

3. **روش‌های هموارسازی (Smoothing):**
   - **Smoothing by Bin Mean:** جایگزینی مقادیر با میانگین هر bin
   - **Smoothing by Bin Median:** جایگزینی مقادیر با میانه هر bin
   - **Smoothing by Bin Boundaries:** جایگزینی با نزدیک‌ترین مرز bin

4. **مقایسه بصری:**
   - رسم هیستوگرام قبل و بعد از هموارسازی

#### کاربرد:
- کاهش نویز در داده
- تبدیل متغیرهای پیوسته به گسسته
- مقابله با outliers

### سؤال 3: استخراج و انتخاب ویژگی

**فایل:** `question3_pca_feature_selection.py`

**دیتاست:** Wine Quality (از UCI Repository)

**هدف:** مقایسه روش‌های کاهش ابعاد و انتخاب ویژگی

#### مراحل انجام کار:

1. **بارگذاری و آماده‌سازی داده:**
   - دانلود دیتاست از UCI
   - تبدیل مسئله به دسته‌بندی باینری (کیفیت > 5 یا ≤ 5)
   - استانداردسازی ویژگی‌ها

2. **PCA (Principal Component Analysis):**
   - اعمال PCA برای استخراج مؤلفه‌های اصلی
   - محاسبه تعداد مؤلفه‌های لازم برای حفظ 95% واریانس
   - نتیجه: معمولاً 9 مؤلفه از 11 ویژگی

3. **Feature Selection با Mutual Information:**
   - انتخاب 2 ویژگی با بیشترین اطلاعات متقابل با کلاس هدف
   - نتیجه: معمولاً `volatile acidity` و `alcohol`

4. **مقایسه عملکرد Logistic Regression:**
   - داده کامل (11 ویژگی)
   - PCA (9 مؤلفه)
   - 2 ویژگی انتخاب‌شده

#### نکات کلیدی:
- **PCA:** ویژگی‌های جدید ترکیبی از ویژگی‌های اصلی هستند (تفسیرپذیری کمتر)
- **Feature Selection:** ویژگی‌های اصلی حفظ می‌شوند (تفسیرپذیری بیشتر)
- کاهش ویژگی‌ها می‌تواند سرعت آموزش را افزایش دهد

### سؤال 4: مدیریت داده‌های نامتوازن

**فایل:** `question4_imbalanced_data.py`

**دیتاست:** Breast Cancer (از Scikit-learn)

**هدف:** درک مشکلات داده‌های نامتوازن و معیارهای ارزیابی مناسب

#### مراحل انجام کار:

1. **بارگذاری و بررسی توزیع:**
   - کلاس Benign (خوش‌خیم): ~63%
   - کلاس Malignant (بدخیم): ~37%

2. **رسم نمودار پای:**
   - نمایش توزیع کلاس‌ها

3. **ایجاد عدم تعادل بیشتر:**
   - کاهش کلاس اقلیت برای ایجاد نسبت 80/20

4. **آموزش مدل و ارزیابی:**
   - آموزش Logistic Regression
   - محاسبه معیارهای مختلف

#### معیارهای ارزیابی:

| معیار | توضیح | فرمول |
|-------|-------|-------|
| **Accuracy** | درصد پیش‌بینی‌های صحیح | (TP+TN)/(TP+TN+FP+FN) |
| **Precision** | از پیش‌بینی‌های مثبت، چند درصد واقعاً مثبت بودند | TP/(TP+FP) |
| **Recall** | از موارد واقعاً مثبت، چند درصد درست پیش‌بینی شدند | TP/(TP+FN) |
| **F1-Score** | میانگین هارمونیک Precision و Recall | 2×(P×R)/(P+R) |

#### چرا Accuracy کافی نیست؟
در داده‌های نامتوازن، مدل می‌تواند فقط کلاس اکثریت را پیش‌بینی کند و همچنان Accuracy بالایی داشته باشد. مثلاً اگر 90% داده‌ها کلاس A باشند، مدلی که همیشه A پیش‌بینی کند، 90% Accuracy دارد!

#### در مسائل پزشکی:
**Recall** اهمیت بیشتری دارد زیرا عدم تشخیص یک بیمار (False Negative) می‌تواند خطرناک باشد.

### نمایش متن فارسی در نمودارها
برای نمایش صحیح متن فارسی در matplotlib، از کتابخانه‌های `arabic_reshaper` و `python-bidi` استفاده شده است:

```python
import arabic_reshaper
from bidi.algorithm import get_display

def persian_text(text):
    reshaped = arabic_reshaper.reshape(text)
    return get_display(reshaped)

plt.title(persian_text('عنوان فارسی'))
```

## 📖 مفاهیم کلیدی

### نرمال‌سازی (Normalization)
- **چرا؟** الگوریتم‌های مبتنی بر فاصله (مثل KNN) به مقیاس ویژگی‌ها حساس هستند
- **Min-Max:** داده را به بازه [0,1] می‌برد
- **Z-score:** داده را با میانگین 0 و انحراف معیار 1 استاندارد می‌کند

### باینینگ (Binning)
- تبدیل متغیر پیوسته به گسسته
- کاهش تأثیر نویز و outliers

### PCA
- کاهش ابعاد با حفظ حداکثر واریانس
- ویژگی‌های جدید مستقل از هم هستند

### داده‌های نامتوازن
- وقتی یک کلاس بیشتر از دیگری است
- راه‌حل‌ها: Oversampling، Undersampling، تغییر آستانه، وزن‌دهی به کلاس‌ها
